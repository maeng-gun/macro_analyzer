# Valley AI 매크로 뉴스 스크랩 스킬 (valley_ai_scrap)

이 스킬은 사용자의 지시(자연어 날짜)를 해석하여, 결정론적인 파이썬 스크립트(`scripts/scrap_valley_news.py`)를 통해 크롤링 파이프라인을 구동하는 역할을 수행합니다.

## 작동 규칙 (규범적 지시사항)

1. **사용자 요청 분석**:
   - 사용자가 "이번 주 소식 긁어와", "어제 뉴스 스크랩해줘"와 같이 모호한 날짜를 지시하면, 현재 시스템 날짜를 기준으로 정확한 `YYYY-MM-DD` 형태의 `start_date`와 `end_date`를 도출하세요.
   - 예: 사용자가 "오늘"을 지시하면 start_date와 end_date는 모두 오늘 날짜입니다.

2. **파이썬 스크립트 실행**:
   - 도출된 날짜를 활용하여 아래의 터미널 명령어를 실행하세요.
   - 실행 명령어: `python scripts/scrap_valley_news.py --start <YYYY-MM-DD> --end <YYYY-MM-DD>`
   - 작업 디렉토리(CWD)는 프로젝트의 루트 폴더여야 합니다.

3. **결과 보고 및 모듈화 종료 (Handoff)**:
   - 스크립트 실행이 완료되면, 터미널에 출력된 stdout(표준 출력) 내용을 읽고 사용자에게 요약하여 보고하세요.
   - "월가 소식 O건, 인사이트 X건 수집이 완료되었습니다."라고 명확히 안내합니다.
   - 해당 날짜에 수집된 데이터가 없다면(0건) 그 사실도 투명하게 전달합니다.
   - **중요**: 이 스킬은 순수 데이터 수집용이므로, 결과를 보고한 뒤에는 추가적인 분석 스킬을 알아서 호출하지 말고 **대기 상태(단순 종료)**로 들어가십시오.
